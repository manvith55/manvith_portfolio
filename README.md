# Manvith Kumar - Modern React Portfolio

A modern, interactive portfolio website built with React and Vite featuring a professional developer showcase with smooth animations, responsive design, and interactive components.

## 🚀 Features

- **React Components**: Modular, reusable component architecture
- **Modern Design**: Professional 2026-style UI with glassmorphism effects
- **Interactive Elements**: Hover effects, animations, and dynamic content
- **Responsive Design**: Mobile-first approach, works on all devices
- **Smooth Animations**: Fade-up, slide-in, and floating effects
- **Fast Performance**: Built with Vite for optimal speed
- **Accessibility**: Semantic HTML, keyboard navigation, reduced motion support

## 🛠️ Installation & Setup

1. **Navigate to project directory**
   ```bash
   cd portfolio
   ```

2. **Install dependencies**
   ```bash
   npm install
   ```

3. **Start development server**
   ```bash
   npm run dev
   ```
   The app will open at `http://localhost:3000`

4. **Build for production**
   ```bash
   npm run build
   ```

5. **Preview production build**
   ```bash
   npm run preview
   ```
